# Clinical Pathway Process Mining

## Project Overview
This project analyzes hospital OPD (Outpatient Department) activity data to understand patient-care workflows and process transitions.

The goal is to explore the sequence of healthcare activities and identify common pathways using Python and Power BI.

## Project Objectives
- Prepare and clean healthcare activity data.
- Transform activity timestamps into an event log.
- Explore activity sequences and process transitions.
- Visualize workflow patterns and key findings.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Power BI
- GitHub

## Project Workflow
1. Data collection and understanding
2. Data cleaning and preparation
3. Event log generation using Python
4. Process transition analysis
5. Dashboard development in Power BI

## Important Note
This project is for analytical and educational purposes. The event log and process-transition results are provisional and require validation of case identifiers, timestamps, duplicate records, and activity ordering.

No patient-level data is included in this repository.
